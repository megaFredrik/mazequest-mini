MazeQuest Mini — UI mockups

Three screens, one visual language: moss-green stone, warm sand floors, an amber lantern. These are the reference frames the build was made against. The maze frame below renders the actual level layout used in index.html, so the mockup and the game cannot drift apart.

Screen 01 — Start menu

The job of this screen is to get someone into the maze in one click, and to teach three rules on the way in. Pip is animated in the real build; the lantern glow is the signature element.

Chain: lever → gate → key → door → portal. Each lock is the only route to the next.
Danger: spike tiles flash coral for half a beat before they extend, so a patient player is never punished.
Feedback: a toast appears at the top of the playfield for every pickup, refusal, and unlock.
